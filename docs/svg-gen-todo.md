## 5. Архитектурные улучшения

### Remark-плагин для автообработки плейсхолдеров в .md
**Проблема:** сейчас `apply-to-file.ts` **потребляет** плейсхолдеры в .md файле — они заменяются на инлайн SVG. Если рендерер улучшится, старые статьи не обновятся.

**Решение:** написать remark-плагин, который при сборке Astro находит плейсхолдеры и заменяет их на SVG в рендере HTML. Тогда:
- В .md остаются плейсхолдеры (source of truth)
- Каждая пересборка использует свежую версию рендерера
- Плейсхолдер = «подписка на улучшения рендера»

**Задачи:**
- [ ] Создать `src/scripts/svg-gen/remark-plugin.ts`
- [ ] Подключить в `astro.config.mjs` → `markdown.remarkPlugins`
- [ ] Убрать вызов `processSvgPlaceholders` из пайплайна (либо оставить как «эмит снапшота на момент публикации» — дискуссия)

### Защитить `/dev/svg-preview` от продакшена
Сейчас он собирается в prod (хоть и со stub-сообщением). Можно исключить через `astro.config.mjs` `build.excludePages` или переместить в отдельный проект.

## 6. SVG-рендер — мелкие косметические штуки

- [ ] **Легенда dc** использует старый API `dcStitch` (прямая палочка + тик). Визуально отличается от V-силуэта в кластерах. Не критично, но не очень консистентно.
- [ ] **Арки на corner-узлах**: `outX, outY = (cos(angle), sin(angle))` нормализовано — работает для квадрата. Для шестиугольника/восьмиугольника нужно переосмыслить при добавлении `circular-round`.
- [ ] **Мобильная адаптация**: viewBox фиксированный, SVG масштабируется через `width: 100%` — мелкие символы становятся совсем крошечными на телефоне. Возможно нужен `min-width` или отдельный mobile breakpoint.
- [ ] **Разные пропорции палитры**: при 2-3 цветах палитра растянута неудачно. Пересмотреть `SWATCH_W/GAP`.
