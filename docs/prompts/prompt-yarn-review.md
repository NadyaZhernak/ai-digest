# Промпт: Обзор трендовой пряжи (casual-style)

## Как использовать

Скопируй блок ниже и отправь Claude. Входные данные не нужны — Claude сам определяет актуальные тренды.

---

## Инструкция для Claude

Напиши статью-обзор трендовой пряжи. Самостоятельно определи 3–4 самые актуальные пряжи прямо сейчас — опирайся на подиумные тренды, популярность в handmade-сообществах (Pinterest, Ravelry, TikTok) и составы, которые сейчас на слуху.

### Формат статьи

Статья должна начинаться с frontmatter:

```markdown
---
title: 'Разговорный заголовок — про пряжу, которую все хотят'
description: 'Краткое описание (2–3 предложения), живым языком'
pubDate: 'YYYY-MM-DD'
tags: ['yarn', 'trends', ...]
---
```

> ⚠️ **pubDate** — всегда сегодняшняя дата в формате ISO: `YYYY-MM-DD`. Никаких `DD.MM.YYYY` — Astro парсит их неверно.

### Структура

1. **Вступление** — о чём сейчас хайп в мире пряжи. Почему именно эти материалы, без занудного перечисления.
2. **SVG — карточки пряжи** — визуальный обзор 3–4 вариантов (см. ниже).
3. **По каждой пряже** — под что подходит (изделие, техника), один практический лайфхак по работе с ней.
4. **Финал** — что брать в первую очередь, коротко и без воды. Можно с лёгкой иронией.

**Объём:** 300–500 слов текста (SVG-код в счёт не идёт).  
**Язык:** русский, **разговорный стиль** — как подружка-эксперт объясняет в чате.

> ⚠️ **ОБЯЗАТЕЛЬНО:** SVG генерировать ТОЛЬКО как `<svg>...</svg>` прямо в тексте. Никаких code-блоков, никаких ASCII-таблиц. Если не вставил SVG — статья не готова.

### Тон и лексика

- Говори «ты», никаких «вы» и официоза
- Можно: «короч», «ну и», «не парься», «вот и всё», «честно говоря»
- Термины объяснять в скобках — просто, без занудства
- Можно пошутить над типичными страхами («да, мохер лезет везде, но оно того стоит»)

### SVG — Карточки пряжи с иллюстрацией текстуры

Сгенерируй SVG с карточками для каждой пряжи. В верхней части каждой карточки — **иллюстрация текстуры** (не просто цветной прямоугольник, а рисованная имитация внешнего вида пряжи). Внизу — характеристики.

**Компоновка:** 3–4 карточки горизонтально (или 2×2 если 4 штуки), каждая ~155×205px. Использовать `clipPath` чтобы иллюстрация не вылезала за границы карточки.

**Верхняя часть карточки (~105px высотой) — иллюстрация текстуры:**

Для каждого типа пряжи — своя техника рисования:

- **Мохер / пушистая пряжа** — цветной фон + две overlapping `<path>`: первый широкий (stroke-width 14–16) с `filter="feGaussianBlur stdDeviation=5"` и opacity 0.8 для гало, второй тонкий (stroke-width 2) поверх для основной нити. Путь — синусоида через всю карточку.
- **Букле** — цветной фон + волнистый `<path>` основной нити + `<circle>` вдоль него (r=4–6, fill=none, stroke) для петель-узлов. Чередовать круги выше и ниже штриха.
- **Шерсть / меринос** — цветной фон + 3–4 скрученные нити: параллельные синусоиды со сдвигом фазы, stroke-width 2–3, чуть разные оттенки.
- **Хлопок / лён / рафия** — цветной фон + 6–8 горизонтальных слабоволнистых линий (`<path>` с пологими Q-кривыми), разные оттенки одного цвета, opacity 0.7–1, имитируют плоские волокна.
- **Трикотажная / толстая пряжа** — цветной фон + 2–3 крупные синусоиды stroke-width 5–8, слегка разнесённые по Y.

**Нижняя часть карточки — текст:**
- Название пряжи (font-size 12, font-weight bold, fill="#333")
- Состав — коротко (font-size 10, fill="#666")
- Метраж (font-size 10, fill="#666")
- Фактура одним словом курсивом (font-size 10, fill="#aaa", font-style="italic")

**Стиль карточки:** белый фон, `stroke="#e0e0e0"`, `rx="8"`. Текст `font-family="sans-serif"`.  
`viewBox` адаптивный, `width="100%"`, `max-width: 560px`.  
Вставить прямо в Markdown как блок `<svg>...</svg>`.

### Важно

- Пряжу выбирай реальную или правдоподобную — с реальными составами и характеристиками.
- Не перечисляй пряжи списком в тексте — это скучно. Дай каждой «характер»: для кого она, в чём её фишка.
- Если пряжа капризная в работе — обязательно упомяни лайфхак (например, как блокировать мохер или с какими спицами работать с букле).
