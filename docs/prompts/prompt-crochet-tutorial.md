# Промпт: Статья-туториал по вязанию крючком (casual-style)

## Как использовать

Скопируй блок ниже, заполни входные данные и отправь Claude.

---

## Входные данные

```
Тип: крючок
Изделие: [название, например: шапка, сумка, топ, игрушка амигуруми]
Уровень: [новичок / средний / продвинутый]
Размер: [параметры или стандарт, например: обхват головы 56–58 см]
Пряжа: [толщина, состав, бренд — опционально]
Особенности: [опционально — вязание по кругу / рядами, особый узор, рельеф]
```

---

## Инструкция для Claude

Напиши статью-туториал о вязании **[изделие]** крючком.

### Формат статьи

Статья должна начинаться с frontmatter:

```markdown
---
title: 'Разговорный заголовок — как будто советуешь подруге'
description: 'Краткое описание (2–3 предложения), живым языком'
pubDate: 'YYYY-MM-DD'
tags: ['crochet', ...]
---
```

> ⚠️ **pubDate** — всегда сегодняшняя дата в формате ISO: `YYYY-MM-DD`. Никаких `DD.MM.YYYY` — Astro парсит их неверно.

### Структура

1. **Вступление** — как будто пишешь подруге в мессенджер. Без пафоса, с юмором, снимай страх перед изделием.
2. **Что понадобится** — список коротко, без воды.
3. **Конструктивная схема** — SVG-диаграмма изделия (см. ниже).
4. **Пошаговая схема вязания** — те же шаги, но заголовки живые (не «Шаг 1», а «Набираем цепочку — главное не запутаться»). Чекпоинты оставить, но формулировать по-человечески.
5. **Схема узора** — SVG-сетка с символами петель (если есть нетривиальный узор).
6. **Финал** — коротко и без пафоса. Можно с лёгкой иронией.

**Объём:** 300–500 слов текста (SVG-код в счёт не идёт).  
**Язык:** русский, **разговорный стиль** — как подружка-эксперт объясняет в чате.

> ⚠️ **ОБЯЗАТЕЛЬНО:** Схемы вставлять как JSON-плейсхолдеры `<!--svg:type {...} -->`. Генератор заменит их на SVG. Никаких code-блоков с символами, никаких ASCII-таблиц. Если нет плейсхолдеров — статья не готова.

### Тон и лексика

- Говори «ты», никаких «вы» и официоза
- Можно: «короч», «ну и», «не парься», «вот и всё», «честно говоря»
- Термины объяснять в скобках или через тире — просто, без занудства
- Можно пошутить над типичными страхами новичков
- Чекпоинты формулировать живо: не «Чекпоинт ✓ — 45 вп», а «Окей, 45 петель — цепочка готова ✓»

### SVG-диаграммы — через плейсхолдеры

Вместо написания SVG-кода используй JSON-плейсхолдеры в HTML-комментариях. Генератор автоматически заменит их на готовый SVG (это делает шаг пайплайна перед записью статьи).

#### ⚠️ Правила визуальной целостности

1. **Палитра ВСЕГДА первая.** Если в статье есть цвета — `<!--svg:palette ...-->` идёт перед любой другой диаграммой.
2. **Цвета в остальных диаграммах — по индексу из палитры** (`0`, `1`, `2`...), а не hex. Это гарантирует, что цвета в палитре, схеме вязания и раскладке совпадут.
3. **Хекс-цвет в `color` допустим только если нет палитры** в статье.

#### Типы плейсхолдеров

**`svg:palette`** — палитра сезона/проекта (2–6 цветов):
```
<!--svg:palette {
  "title": "Палитра сезона 2026",
  "colors": [
    {"name": "Pattina Blue", "hex": "#2B6A8A"},
    {"name": "Ice Blue",     "hex": "#8DB9D4"},
    {"name": "Горчица",      "hex": "#D4A843"},
    {"name": "Терракота",    "hex": "#C26B4A"}
  ]
}-->
```

**`svg:stitch-chart` (circular)** — радиальный мотив: бабушкин квадрат, солнышко, шестиугольник. Рендерер сам рисует столбики V-силуэтом со сходящимся основанием и воздушные петли дугами. Повтор `repeat:4` — квадратный мотив (4-сторонняя симметрия).

```
<!--svg:stitch-chart {
  "title": "Схема бабушкиного квадрата — 3 раунда",
  "layout": "circular",
  "center": "magic-ring",
  "rounds": [
    {"label": "Раунд 1", "color": 3, "pattern": "3dc, ch2", "repeat": 4, "note": "12 dc, 4 ch-2"},
    {"label": "Раунд 2", "color": 2, "pattern": "3dc, ch2, 3dc, ch1", "repeat": 4, "note": "24 dc"},
    {"label": "Раунд 3", "color": 0, "pattern": "3dc, ch1, 3dc, ch2, 3dc, ch1", "repeat": 4, "note": "36 dc"}
  ]
}-->
```

Конвенция для granny-подобных узоров:
- `ch2` — это УГЛОВАЯ арка. Первая `chN≥2` выравнивается по диагонали квадрата (NE).
- `ch1` — межкластерная арка на стороне.
- Клaстер = подряд идущие не-ch стежки (`3dc`, `6dc`, `2tr`...), они сходятся к общей точке основания.

**`svg:stitch-chart` (grid)** — плоский крючок по рядам:
```
<!--svg:stitch-chart {"title":"Тело шапки","layout":"grid","craft":"crochet","cols":8,"rows":[{"label":"1-10","pattern":"hdc","repeat":8}],"legend":true} -->
```

**`svg:garment-layout`** — раскладка деталей изделия (один или несколько вариантов):
```
<!--svg:garment-layout {
  "title": "Раскладка деталей — три варианта",
  "variants": [
    {
      "name": "Жилет",
      "color": 0,
      "pieces": [
        {"name": "Спинка", "cols": 2, "rows": 2},
        {"name": "Полочка", "cols": 1, "rows": 2, "qty": 2}
      ],
      "total": {"count": 8, "formula": "2x2 + 1x2 x2"}
    }
  ]
}-->
```

`color` у варианта — индекс палитры для акцентной рамки и бейджа.

#### Формат `pattern`

`{count}{stitch}` через запятую. Петли: `ch` (воздушная), `sc` (без накида), `hdc` (полустолбик), `dc` (с накидом), `tr` (2 накида), `dtr` (3 накида), `inc` (прибавка), `dec` (убавка). Примеры: `"3dc, ch2"`, `"6dc, ch2"`, `"sc, inc"`, `"hdc"`.

#### Порядок плейсхолдеров в статье

1. `<!--svg:palette ...-->` — сразу после раздела «Цвета/палитра» (или после первого абзаца, если статья про колор)
2. `<!--svg:stitch-chart ...-->` — в разделе «Схема узора / Конструкция»
3. `<!--svg:garment-layout ...-->` — в разделе «Раскладка / Из чего состоит»

#### Если плейсхолдеры не обработались

Статью уже положили в `src/content/blog/`, а диаграммы видны как HTML-комментарии? Запусти:
```
npx tsx src/scripts/svg-gen/apply-to-file.ts src/content/blog/<file>.md
```
Генератор обработает плейсхолдеры in-place.

### Петли, доступные в `pattern`

В плейсхолдере указывается shorthand (не Unicode-символ) — рендерер сам нарисует правильный CRA-символ.

| shorthand | Петля |
|-----------|-------|
| `ch` | Воздушная петля |
| `sl` | Соединительный столбик |
| `sc` | Столбик без накида |
| `hdc` | Полустолбик с накидом |
| `dc` | Столбик с накидом |
| `tr` | Столбик с двумя накидами |
| `dtr` | Столбик с тремя накидами |
| `inc` | Прибавка (2 ст. в одну п.) |
| `dec` | Убавка (2 п. вместе) |

Если нужна петля, которой нет в списке (попкорн, шишечка, рельефный) — добавь её через `note` у раунда, а в `pattern` используй ближайший эквивалент.

---

### Важно

- Используй термины крючка, но объясняй их по-человечески: не «провяжи ССН», а «столбик с накидом — вот как это делается».
- Чётко различай вязание по кругу (раунды) и рядами (ряды с поворотом).
- При вязании по кругу указывай: замкнутый раунд (соединительным столбиком) или непрерывная спираль.
- Плейсхолдеры вставляй непосредственно в текст статьи в нужном месте — не в конец, не в отдельный блок.
