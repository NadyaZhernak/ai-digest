# Промпт: Статья-туториал по вязанию крючком (formal-style)

## Как использовать

Скопируй блок ниже, заполни входные данные и отправь Claude.

---

## Входные данные

```
Тип: крючок
Изделие: [название, например: шапка, сумка, топ, игрушка амигуруми]
Уровень: [новичок / средний / продвинутый]
Размер: [параметры или стандарт, например: обхват головы 56–58 см]
Пряжа: [толщина, состав, бренд — опционально]
Особенности: [опционально — вязание по кругу / рядами, особый узор, рельеф]
```

---

## Инструкция для Claude

Напиши статью-туториал о вязании **[изделие]** крючком.

### Формат статьи

Статья должна начинаться с frontmatter:

```markdown
---
title: 'Информативный заголовок с указанием изделия и техники'
description: 'Краткое описание (2–3 предложения) с указанием уровня сложности и ключевых техник'
pubDate: 'YYYY-MM-DD'
tags: ['crochet', ...]
---
```

> ⚠️ **pubDate** — всегда сегодняшняя дата в формате ISO: `YYYY-MM-DD`. Никаких `DD.MM.YYYY` — Astro парсит их неверно.

### Структура

1. **Введение** — краткое описание изделия, его назначения и особенностей техники исполнения.
2. **Необходимые материалы и инструменты** — точный перечень с указанием характеристик.
3. **Конструктивная схема** — SVG-диаграмма изделия (см. ниже).
4. **Пошаговое описание вязания** — чёткие заголовки разделов («Начальная цепочка», «Основное полотно», «Убавки» и т.д.). Контрольные точки обязательны.
5. **Схема узора** — SVG-сетка с символами петель (если есть нетривиальный узор).
6. **Заключение** — рекомендации по отделке, блокировке и хранению готового изделия.

**Объём:** 300–500 слов текста (SVG-код в счёт не идёт).  
**Язык:** русский, **формальный стиль** — профессиональный, точный, без разговорных оборотов.

> ⚠️ **ОБЯЗАТЕЛЬНО:** Схемы генерировать ТОЛЬКО как `<svg>...</svg>` прямо в тексте. Никаких code-блоков с символами, никаких ASCII-таблиц вместо SVG. Если не вставил SVG — статья не готова.

### Тон и лексика

- Обращение на «вы»
- Профессиональная терминология: «провяжите», «выполните цепочку», «введите крючок»
- Термины приводить с расшифровкой в скобках при первом упоминании: «убавка (2 петли вместе — dec)»
- Контрольные точки формулировать точно: «Контрольная точка: 45 воздушных петель ✓»
- Никаких разговорных оборотов, шуток и неформальных отступлений

---

### SVG 1 — Конструктивная схема изделия

Сгенерируй SVG с силуэтом изделия. Требования:

- Геометрические фигуры, отражающие форму изделия
- Подписанные зоны (начальная цепочка, тело, убавки, края и т.д.)
- Размерные стрелки с подписями (ширина, высота каждой зоны в см)
- Стиль: минималистичный, монохромный (`stroke="#333"`, `fill="none"`)
- `viewBox` адаптивный, `width="100%"`, `max-width: 400px`
- Вставить прямо в Markdown как блок `<svg>...</svg>`

### SVG 2 — Схема узора (если есть нетривиальный узор)

Для крючка схема может быть двух типов — выбери подходящий:

**Тип A — Линейная сетка** (для изделий вязанных рядами):
- Прямоугольная сетка, каждая ячейка ~24×24px
- Символы по таблице ниже, по центру ячейки
- Номера рядов слева (снизу вверх), номера петель снизу (справа налево)
- Легенда под схемой

**Тип B — Радиальная/круговая схема** (для изделий вязанных по кругу):
- Концентрические дуги или полукруги, обозначающие раунды
- Символы петель расставлены по дугам
- Подпись номеров раундов
- Легенда рядом

Стиль для обоих: линии `stroke="#ccc"`, символы `fill="#333"`, `font-size="14"`

### Таблица символов крючка (стандарт CRA)

Используй только эти символы в SVG-схеме. Выбирай нужные в зависимости от узора:

| Символ | Английское название | Русское название |
|--------|---------------------|-----------------|
| ⋯ | Slip knot | Скользящий узел |
| ⊕ | Magic ring | Магическое кольцо |
| ○ | Chain stitch (ch) | Воздушная петля |
| • | Slip stitch (sl st) | Соединительный столбик |
| + | Single crochet (sc) | Столбик без накида |
| T | Half double crochet (hdc) | Полустолбик с накидом |
| ╥ | Double crochet (dc) | Столбик с накидом |
| ╦ | Treble crochet (tr) | Столбик с двумя накидами |
| ╩ | Double treble (dtr) | Столбик с тремя накидами |
| ╬ | Triple treble (trtr) | Столбик с четырьмя накидами |
| ✕ | Decrease (dec) | Убавка (2 п. вместе) |
| V | Increase (inc) | Прибавка (2 ст. в одну п.) |
| ⋒ | Bobble | Бобл |
| ❋ | Popcorn | Попкорн |
| ◈ | Cluster | Кластер |
| ⌒ | Shell | Ракушка |
| ↑ | Front post stitch (FP) | Рельефный столбик по лицевой |
| ↓ | Back post stitch (BP) | Рельефный столбик по изнаночной |

---

### Важно

- Используй корректную терминологию вязания крючком.
- Чётко различай вязание по кругу (раунды) и рядами (ряды с поворотом).
- При вязании по кругу указывай: замкнутый раунд (соединительным столбиком) или непрерывная спираль.
- SVG вставляй непосредственно в текст статьи в нужном месте.
