# Промпт: Статья-туториал по вязанию на спицах (formal-style)

## Как использовать

Скопируй блок ниже, заполни входные данные и отправь Claude.

---

## Входные данные

```
Тип: спицы
Изделие: [название, например: шапка бини, свитер оверсайз, носки]
Уровень: [новичок / средний / продвинутый]
Размер: [параметры или стандарт, например: обхват головы 56–58 см]
Пряжа: [толщина, состав, бренд — опционально]
Особенности: [опционально — фактура, цветовые блоки, особый узор]
```

---

## Инструкция для Claude

Напиши статью-туториал о вязании **[изделие]** на спицах.

### Формат статьи

Статья должна начинаться с frontmatter:

```markdown
---
title: 'Информативный заголовок с указанием изделия и техники'
description: 'Краткое описание (2–3 предложения) с указанием уровня сложности и ключевых техник'
pubDate: 'YYYY-MM-DD'
tags: ['knitting', ...]
---
```

> ⚠️ **pubDate** — всегда сегодняшняя дата в формате ISO: `YYYY-MM-DD`. Никаких `DD.MM.YYYY` — Astro парсит их неверно.

### Структура

1. **Введение** — краткое описание изделия, его назначения и особенностей техники исполнения.
2. **Необходимые материалы и инструменты** — точный перечень с указанием характеристик.
3. **Конструктивная схема** — SVG-диаграмма изделия (см. ниже).
4. **Пошаговое описание вязания** — чёткие заголовки разделов («Набор петель», «Вязание резинки», «Основное полотно» и т.д.). Контрольные точки обязательны.
5. **Схема узора** — SVG-сетка с символами петель (если есть нетривиальный узор).
6. **Заключение** — рекомендации по отделке, блокировке и хранению готового изделия.

**Объём:** 300–500 слов текста (SVG-код в счёт не идёт).  
**Язык:** русский, **формальный стиль** — профессиональный, точный, без разговорных оборотов.

> ⚠️ **ОБЯЗАТЕЛЬНО:** Схемы генерировать ТОЛЬКО как `<svg>...</svg>` прямо в тексте. Никаких code-блоков с символами, никаких ASCII-таблиц вместо SVG. Если не вставил SVG — статья не готова.

### Тон и лексика

- Обращение на «вы»
- Профессиональная терминология: «провяжите», «наберите», «выполните убавку»
- Термины приводить с расшифровкой в скобках при первом упоминании: «убавка SSK (две петли вместе за заднюю стенку)»
- Контрольные точки формулировать точно: «Контрольная точка: 88 петель на спицах ✓»
- Никаких разговорных оборотов, шуток и неформальных отступлений

---

### SVG 1 — Конструктивная схема изделия

Сгенерируй SVG с силуэтом изделия. Требования:

- Геометрические фигуры, отражающие форму изделия
- Подписанные зоны (резинка, тело, рукав, убавки и т.д.)
- Размерные стрелки с подписями (ширина, высота каждой зоны в см)
- Стиль: минималистичный, монохромный (`stroke="#333"`, `fill="none"`)
- `viewBox` адаптивный, `width="100%"`, `max-width: 400px`
- Вставить прямо в Markdown как блок `<svg>...</svg>`

### SVG 2 — Сетка узора (если есть нетривиальный узор)

Сгенерируй SVG-сетку паттерн-repeat. Требования:

- Прямоугольная сетка, каждая ячейка ~24×24px
- Символы петель по таблице ниже, по центру ячейки
- Подпись номеров рядов слева (читать снизу вверх)
- Подпись номеров петель снизу (читать справа налево — стандарт)
- Легенда под схемой: символ + расшифровка
- Показывать только паттерн-repeat (не все ряды изделия)
- Стиль: линии `stroke="#ccc"`, символы `fill="#333"`, `font-size="14"`

---

### Таблица символов спиц

Используй только эти символы в SVG-сетке:

| Символ | Значение |
|--------|----------|
| □ | Лицевая петля (knit) |
| – | Изнаночная петля (purl) |
| ○ | Накид (yarn over) |
| \ | Убавка влево: 2 п. вместе за заднюю стенку (SSK) |
| / | Убавка вправо: 2 п. вместе (k2tog) |
| X | Перекрёст 2 п. (cable cross) |
| ▽ | Центральная двойная убавка (CDD) |
| ↑ | Снятая петля (slip stitch) |
| ◻ | Нет петли (no stitch) |

---

### Важно

- Используй корректную терминологию вязания на спицах.
- Чётко разграничивай круговое вязание (раунды) и плоское вязание (ряды с поворотом).
- SVG вставляй непосредственно в текст статьи в нужном месте.
