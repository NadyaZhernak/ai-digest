# Критерии отбора новостей

- **Актуальность:** новость опубликована не более 3 месяцев назад.
- **Тематика:** только вязание спицами и крючком — тренды, техники, пряжа, цвета сезона, микротренды.
- **Уникальность:** тема не дублирует существующие статьи (проверять по заголовкам и тегам в `src/content/blog/`).
- **Аудитория:** предпочтение темам, интересным и новичкам, и профи.
- **Источники:** приоритет — Ravelry, Vogue Knitting, Interweave; крупные соцсети (Pinterest, TikTok, Instagram).

# Редакционная политика

- Одна статья за запуск. Нет уникальной темы — пайплайн завершается без публикации.
- Статья публикуется только вместе с обложкой. Нет обложки — нет публикации (до 3 попыток).
- Промпт для Replicate формируется на основе содержания **готовой** статьи.
- Все статьи проходят через Pull Request для возможности отката.
